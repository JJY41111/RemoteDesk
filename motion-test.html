動態畫面測試

00000000
每次瀏覽器畫面更新回呼加 1 · 色塊每 4 秒完成一次來回

01 — 連續移動測試：觀察上方色塊是否平順往返，有沒有突然停住、跳動或拖影。

02 — 影格計數測試：大字數字在每次 requestAnimationFrame 回呼時遞增，可比較主機與遠端畫面顯示的數值。

03 — 文字清晰度測試：這段文字會持續向上捲動。請觀察中文字、標點與細節是否清楚，移動時是否變得模糊。

04 — 程式碼閱讀測試：for (int frame = 0; frame < 600; ++frame) { render(frame); }

05 — 字元辨識測試：ABCDEFGHIJKLMNOPQRSTUVWXYZ · abcdefghijklmnopqrstuvwxyz · 0123456789 · {} [] () <> / \ + - =

06 — 同步觀察：同時查看主機與接收端的色塊位置、數字及文字。此計數器表示瀏覽器更新回呼次數，不代表遠端實際收到的影格數。

07 — 持續循環：接下來文字將無縫重複，方便觀察長時間播放的穩定性。
