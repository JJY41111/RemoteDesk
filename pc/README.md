# RemoteDesk Windows 原生客戶端 0.1

將整個 ZIP 解壓縮到 ASUS 筆電的一個資料夾，再雙擊 `remote_desk_client.exe`。DLL 檔案留在執行檔旁邊。筆電不需要 Node.js、Visual Studio 或瀏覽器。

2026-10-16.1 版加入 GDI 雙緩衝呈現，避免每次重畫先把顯示區清黑。更新時先關閉舊 App，再解壓縮覆蓋程式與 DLL，保留原有 CA 公開憑證檔；視窗標題可核對版本。主機啟動器關閉重開後只顯示兩個跨網路分頁，關閉啟動器不會停止已啟動的服務。

2026-10-16.2 版在啟用遠端操作、主機畫面可用且游標位於影像內時隱藏筆電游標，只保留影像中的主機游標。工具列、影像黑邊、切換視窗、停用操作或斷線時恢復本機游標；一般桌面操作不改動全域 ShowCursor 計數。

2026-10-16.3 版分離收片佇列與顯示影像，GDI 縮放不再占用收片鎖；壓縮影格的短暫突波不會在四張時整批清空。過載仍有張數與年齡上限，重新同步時會重建解碼器。標題改顯示最近一秒的接收／解碼／重畫 FPS 與每幀解碼耗時；「重畫」不是螢幕實際刷新率。斷線後診斷存於 `%LOCALAPPDATA%\RemoteDesk\PC\last-session.json`，不含配對碼。

## 連線

1. 桌機重新開啟 RemoteDesk 啟動器，在「跨網路 筆電」分頁啟動服務。「跨網路 iPad」分頁獨立，不必停止。
2. 將 PC 分頁的 HTTPS 網址貼入 App，輸入該分頁的 8 位配對碼。
3. 主機使用私人 CA 時，從主機取得公開的 `ca.crt`，核對主機顯示的 SHA-256 指紋後複製到筆電，按「選擇 .crt」選取。也可從主機所選網路網址的 `/ca.crt` 取得。不要複製 `ca-key.pem` 或其他私鑰。
4. App 僅在本次連線使用所選 CA 驗證主機的憑證鏈、名稱與有效期，不把 CA 安裝到 Windows。若 CA 欄留空，使用 Windows 既有的憑證信任。
5. 跨網路時兩台電腦須連上可互通的 Tailscale 網路。Windows 防火牆需允許主機 Node.js 與筆電 App 在所用私人網路連線。

筆電服務使用 Tailscale 10443；iPad 使用 9443。主機啟動器只提供這兩個跨網路入口。請以啟動器提供的實際網址為準。

## 操作

- 先勾選「啟用遠端操作」，等待主機確認，再點遠端畫面聚焦鍵盤。
- 「遊戲滑鼠」使用原生相對輸入，Esc 釋放；切到其他視窗也會釋放按鍵與滑鼠。
- 全螢幕保留工具列，可再次按「全螢幕」返回視窗。
- 「XInput 手把」可回傳 Xbox 相容手把；主機仍需既有 VIIPER 驅動與連接器。此版不會安裝驅動。
- 系統快捷鍵仍可能由筆電接收；沒有一般 App 可以完整接管 Ctrl+Alt+Del。
- 畫面模式為「1080p 日常」及「2K 清晰（2560×1440）」，串流目標皆為 60 FPS。2880×1800／90 Hz 是筆電螢幕規格，不代表此版提供該解析度或 90 FPS 串流。
- 主機桌面暫時無法擷取或 Windows 拒絕輸入時，底部狀態列會顯示提示；這不代表可操作 UAC 安全桌面，權限提示仍需在主機處理。

網址、CA 路徑、畫面模式與音訊偏好存於 `%LOCALAPPDATA%\RemoteDesk\PC\settings.json`。配對碼和遠端操作同意不會儲存；PC 的設定不共用 iPad 儲存。

## 版本邊界

這是第一個可執行的原生 Win32／C++／WebRTC 客戶端，使用 Media Foundation 軟體解碼基準與 GDI 呈現，尚未接上原生 GPU 解碼／Direct3D 呈現。
本次驗證是 Windows 同機隔離影音接收與離屏渲染，音訊輸出靜音、未注入鍵鼠。ASUS 實機的聲音播放、鍵鼠、手把、跨網路、中文輸入與長時間穩定性仍待驗收。
原生 App 的剪貼簿／檔案傳輸介面尚未加入；PC 瀏覽器備援已有該功能，目的地是主機的「pc傳輸」。同一 PC 服務一次接一個客戶端。
