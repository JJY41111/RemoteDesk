# 2026-10-04：回到主畫面網頁版

使用者明確要求刪除 App，回到實測最穩定的加入主畫面網頁版本。

- 關閉 GitHub 原生 App 草稿 PR #1，不合併；刪除 `codex/ipad-native-app` 分支。
- 移除本機 Xcode／Swift Playgrounds App 專案、App 編譯工作流程與安裝產物。保留原生失敗診斷文件並標示停止，避免把未驗收游標鎖定說成成功。

- 續作排程改為 PWA 穩定性與跨區遊戲延遲，不再編譯、下載或安裝原生 App。

Windows 已安裝的 iTunes／Apple USB 元件不在此次專案清理範圍，避免再次改動使用者軟體環境；停止本次由助手啟動的 AltServer，取消後續簽署步驟。
