## 本次修改

- 1080p 串流改用 D3D11 Video Processor 從桌面 BGRA 縮放／轉 NV12；不支援時自動退回原 CPU 路徑。這降低主機逐幀轉色負擔，但遊戲負載下的效果仍須 iPad 實測。
- 網路串流時停用無用途的本機預覽複製與 Present，減少與遊戲爭用 GPU 的機會。
- 配對畫面可選 `1080p：遊戲優先`（預設）或 `原生 2560×1440：文字清晰`。原生模式只在 `--display=0:0` 真正是 2560×1440 時啟動；會保留來源像素，避免原先 2560×1440 → 1920×1080 的縮圖損失。放大 150% 只把已有像素放大，無法還原縮圖中失去的字形細節。
- 原生模式將 H.264 SDP 層級設為 5.1，並擴大本地影格封包上限；保留 1080p 的既有格式。配對後改模式需斷線重連。
- CSV 新增 `host_sent_fps`、`host_source_age_ms`，頁面也顯示主機送出 FPS，方便區分主機輸出不足與接收端呈現不足。
