# iPad 剪貼簿、檔案傳輸與遊戲紀錄（2026-10-02）

## 使用方式

與主機配對後，開啟「功能」選單。新介面把原來占位的兩個文字區改成「剪貼簿」及
「檔案傳輸」兩塊；原觸控打字及實體鍵盤診斷收在下方摺疊區，鍵盤控制路徑保留。

- 剪貼簿：在文字框貼上文字，或貼上／選擇圖片，按「送至 Windows 剪貼簿」。
  成功後，在 Windows 應用程式按 Ctrl+V；不會自動把內容貼進當前視窗。
  iPad 瀏覽器若拒絕直接讀剪貼簿，可長按文字框選「貼上」。圖片讀取失敗時可改用
  「選擇圖片」；非 PNG/JPEG 圖片會在瀏覽器嘗試轉為 PNG。單次上限 16 MiB。
- 檔案傳輸：iPad 選取一個或多個檔案，按「傳到電腦」。主機儲存於
  `C:\Users\johnl\Desktop\ipad傳輸`。文件、原始碼、壓縮檔、照片、影片都可選；
  不限制副檔名，單檔上限 4 GiB。同名檔案保留兩份並加編號。上傳不自動開啟檔案。

兩種傳輸都要求同來源網頁、目前已配對工作階段及隨機工作階段權杖；斷線後權杖
失效。檔案以串流寫入暫存檔，完成後才移到接收資料夾，失敗會清掉暫存檔。
使用者正在遊戲時傳大檔仍可能占用網路，與影音／手把的競爭需 iPad 實測。
