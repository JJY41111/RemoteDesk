# 本機 TCP H.264 傳輸驗證（2026-09-16）

## 範圍

將現有 H.264 編碼輸出，以長度明確的封包透過 TCP 從 RemoteDesk 擷取程序
送到獨立接收程序。目前只綁定 `127.0.0.1:5000`，不向區域網路或網際網路
提供桌面畫面。網路接收端**尚未解碼或顯示畫面**。

每個封包含版本、序號、1280×720 解析度、長度與時間戳；接收端檢查順序
與大小，避免把 TCP 的任意接收區塊誤當成完整一幀。傳送工作在獨立執行緒，
最多緩衝 16 個封包，過量時直接回報錯誤，不會無限堆積記憶體。

## 重現方式

1. 執行 `build.bat`。
2. 在第一個終端執行 `out\remote_desk_receiver.exe`。
3. 在第二個終端執行 `out\remote_desk.exe --network-test`。
4. 比對 `runtime.log` 與 `receiver.log` 的封包數、位元組數與校驗值。
