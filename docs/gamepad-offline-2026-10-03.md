# 2026-10-03.2 虛擬手把離線清理

使用者要求：遠端離線時移除 PC 的 RemoteDesk 虛擬 Xbox 手把，避免回到主機玩遊戲仍殘留遠端裝置。此修正不控制實體手把電源，不移除 USBIP 驅動，不停止共用 VIIPER 服務。

## 行為

- 按啟用虛擬手把時建立此工作階段專屬裝置。
- 遠端工作階段結束、WebSocket 關閉、WebRTC 偵測 disconnected/failed/closed，或手把 DataChannel／VIIPER 資料流中斷時，自動歸零並移除該工作階段的虛擬裝置。WebRTC 的畫面恢復寬限仍保留，但虛擬手把不等待寬限結束。
- 重新連線後須重新按啟用，不偷偷重建。
- 若建立裝置尚未完成便斷線，等待建立返回的 bus ID 後移除，避免競爭殘留；移除暫時失敗最多嘗試三次，持續失敗會記錄錯誤，不再靜默吞掉。
- 斷網須先由傳輸層偵測，不能保證拔網線瞬間移除。PC 程序被強制終止／作業系統當機時無法執行清理，尚未做跨程序持久化回收。

## 驗證

26 個 Node 測試通過，新增啟用中斷線、VIIPER 資料流中斷、移除失敗重試測試。隔離 8545/55446 上，以同機 Chrome 連接真實 VIIPER：關閉手把通道後裝置移除且 Peer 仍連線；重新啟用再關閉瀏覽器，VIIPER 完成移除、主機記錄完成。未模擬實際 iPad 斷網，未證明使用者 PC 遊戲卡頓必然由虛擬裝置造成。

驗收：重載新版、啟用手把後中斷遠端，檢查 Windows 遊戲控制器中的 RemoteDesk 虛擬装置消失；回到主機玩遊戲確認體感。既有解析度、編碼率、影音与 UI 排列未作調整。
