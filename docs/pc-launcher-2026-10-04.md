# PC圖形啟動器

桌面雙擊「RemoteDesk啟動器」，選分頁按「開始」。也可以雙擊專案內 `RemoteDesk-Launcher.vbs`。啟動器使用Windows內建PowerShell／WinForms與現有Node.js，不需另裝UI框架。

- **同網路iPad**：自動列出目前連線的實體網卡區網IPv4，使用8443／TCP5000。
- **跨網路iPad**：自動讀取目前Tailscale IPv4，使用9443／TCP55445。PC及iPad需先連上Tailscale；啟動器不自行登入或改動VPN設定。
- **跨網路PC**：只預留分頁，未實作串流或接收端。

兩種iPad模式均保留鍵鼠、音訊、顯示器0:0及按需虛擬手把。畫面解析度仍由iPad配對時選擇。顯示網址及本次配對碼，提供複製按鈕。關閉啟動器不停止服務。

## 服務保護

已經運作中的正式服務會沿用，不重複啟動、不搶占連接埠。運作時開始鈕顯示「已啟動」並停用，停止鈕可用。原來從終端機或助手啟動的服務，核對目前專案的配對狀態檔、PID、主機位址、連接埠與啟動記錄後也可停止；無法核對的其他服務不會被停止。

啟動器新啟動的服務保存PID、程序啟動時間及專案路徑於 `bridge/private/launcher-*.json`；停止前重新核對身分，不只依PID。iPad畫面傳輸仍連線時要求先斷線再停止，避免留下虛擬手把。stdout/stderr在同一private資料夾，不放GitHub；讀取運作中的日誌使用共享讀取，不鎖住Node輸出。

## 驗證

Windows PowerShell 5.1實際啟動獨立19561／19562服務，讀出配對碼、確認再次開始沿用同一PID、核對所有權、停止成功。額外以WinForms實際PerformClick驗證「開始 → 運作 → 停止 → 未啟動」完整隔離流程。既有8443／9443服務核對可管理，測試未停止或重啟；三分頁與正式服務按鈕狀態通過，不代表新增iPad實機串流驗收。
