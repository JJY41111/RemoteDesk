# RemoteDesk iPad 主畫面網頁版

2026-10-04：停止原生 App／Swift Playgrounds 路線，以使用者實測較穩定的主畫面網頁版（PWA）為主要接收器。原生專案與安裝包撤下，GitHub App 草稿 PR 關閉、不合併。

## 使用

1. 跨區先連線 Tailscale，在 Safari 開啟目前主機 HTTPS 網址。
2. Safari 分享選單 →「加入主畫面」，之後從主畫面 RemoteDesk 圖示開啟。
3. 輸入主機當次配對碼、播放畫面；需要操作時勾選「啟用本次遠端操作」。
4. 實體鍵盤使用「功能 → 鍵盤控制」或聚焦遠端畫面；滑鼠、Xbox 手把與音訊沿用既有功能。
5. 「功能」內保留文字／圖片剪貼簿及檔案上傳，送至主機桌面的 `ipad傳輸` 資料夾。

現有主畫面圖示可繼續使用，不需要免費個人簽署或每七天續期。網址、配對碼與 CA 沿用正在執行的服務；主機重啟後以新的配對碼為準。

## 驗證與限制

這次撤回 App 不調整影音碼率、FPS、接收緩衝或排隊參數，不回退先前已驗收的網頁功能。
目前 iPad 網頁第一人稱滑鼠仍有邊界限制，不能宣稱已具備真正游標鎖定或無限轉向。後續改善可量測的 PWA 穩定性與延遲。
App 實驗文件 `docs/native-*.md` 僅作歷史診斷，已停止开发，不再作安裝指引。
