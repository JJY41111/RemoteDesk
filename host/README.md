# Windows 高權限擷取與輸入服務

## 目的與狀態

讓既有 iPad PWA 經原來的 HTTPS／WebRTC 配對，要求受控的 SYSTEM 助手擷取及操作 Windows UAC 安全桌面。網頁伺服器、剪貼簿、檔案傳輸、音訊與手把仍維持原執行權限。

這是需要本機管理員一次授權的主機元件。必須完成安裝後的真實 UAC 驗收，才可宣稱遠端能看到及按下提示；編譯或一般桌面測試不是驗收。

## 信任邊界

- 服務帳號 LocalSystem、自動啟動；不直接監聽 TCP／UDP 網路埠。
- 公開的本機 named pipe 拒絕遠端連線，ACL 只授予安裝時的指定管理員帳號資料讀寫，沒有建立其他 pipe instance 的權限；每次要求再核對 Windows 帳號 SID 及實體主控台工作階段。
- 僅啟動保護目錄內兩個固定助手，參數只能選預定解析度、顯示器及本機傳輸埠。沒有任意命令、路徑、環境變數或工作階段參數入口。
- 私有 agent pipe 只允許 SYSTEM，並核對連線 PID。一般程序不能自行指定管道冒充高權限助手。
- 助手在目前使用者工作階段執行，不嘗試讓 Session 0 服務直接操作桌面。輸入助手以獨立於 DXGI 列舉的執行緒跟隨作用中桌面。
- 每條連線由 kill-on-close Job 管理，客戶端斷線及服務退出會結束助手。輸入關閉前先要求放開按鍵；強制終止或桌面持續不可用的情況仍需實測卡鍵邊界。
- **本機指定帳號的程序也能使用此服務能力。**它是授予該管理員帳號遠端高權限輸入的信任，不是一般帳號可任意使用的多使用者服務。不應授予不受信任帳號，或把已被入侵的本機帳號視為安全。
- 不自動確認 UAC，不儲存管理員密碼，不變更 UAC／安全桌面政策。權限提示若需要帳密，仍由使用者輸入。

## 組件與安裝

1. 從專案根目錄執行 `host\Build-Host.cmd`，產生 `out\system-host\` 中三個獨立執行檔；不替換目前使用中的普通助手。
2. 在主機以同一個管理員帳號開啟管理員 PowerShell，從專案根目錄執行：

```powershell
.\host\Install-Host.ps1
```

安裝到 `%ProgramFiles%\RemoteDeskHost`，日誌位於 `%ProgramData%\RemoteDeskHost`。目錄只允許 SYSTEM／Administrators 修改，普通帳號只能讀取指定內容。安裝器拒絕不受信任的既存目錄及 reparse point，不直接寫入既存 hard link。安裝失敗會移除本次註冊的服務，保留檔案供診斷。

3. 遠端斷線後，重新啟動原啟動器或 `npm.cmd run start:tailnet`。已安裝但不能連接服務時會明確失敗，不偷偷切回無法操作 UAC 的普通模式。直接執行 `server.mjs` 者需明確加 `--system-host`。
4. 工具欄顯示「高權限助手已連接」後，先啟用本次遠端操作，再測真實 UAC。安裝不會自動勾選遠端操作。

## 移除與回復

更新現有服務使用管理員 PowerShell 執行 `host\Update-Host.ps1`。更新器要求沒有活動助手，先保存保護目錄內的舊版本；新版本狀態檢查失敗會還原。不要在活動遠端連線期間更新。

停止遠端操作，再由管理員 PowerShell 執行：

```powershell
.\host\Remove-Host.ps1
```

服務移除後重啟原啟動器，即使用普通模式。保留保護目錄中的執行檔與日誌，不刪除使用者資料、不卸載其他軟體或驅動。

## 驗收要求

- 未配對網頁不可發出輸入；未啟用本次遠端操作時不可操作 UAC。
- 指定帳號、正確主控台工作階段才能連接服務；其他帳號、遠端 pipe、任意命令及路徑均拒絕。
- 真實 UAC：iPad 能看見提示、由 iPad 點「否」，取消後原連線繼續；之後再測允許一個無系統變更的空程序。
- 切換前後測滑鼠、鍵盤、Caps Lock、放鍵與同一配對工作階段；不單以主機 FPS 判定輸入成功。
- 斷線、服務停止時所有 SYSTEM 助手退出；普通模式與原解析度／音訊／傳檔不能退步。
